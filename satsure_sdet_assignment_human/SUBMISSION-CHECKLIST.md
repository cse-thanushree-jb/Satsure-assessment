## Before sending to the interviewer

1. Put the real application URL in `ui.baseUrl`.
2. Put the real API URL/path in `api.baseUrl` and `api.path`.
3. Run the tests in the real environment.
4. Review the test results.
5. Make sure the AI reflection accurately describes your own changes.
6. Commit and push the repository.
